# 设计系统 · 体育场馆预约与赛事排期管理系统

> 方向：**运动钴蓝**。单位内部业务系统质感，重数据可读性与状态辨识，不用巨幅英文口号、装饰光效、悬浮球、大面积插画。卡片圆角 6–8px，阴影只用于抽屉与弹窗。

## 1. 色彩

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 Primary | `#0F3B5D` | 顶栏、主按钮、当前菜单、关键数字 |
| 辅助色 Aux | `#2878B5` | 次级按钮、筛选选中态、普通图表系列 |
| 页面背景 | `#F4F8FB` | 主内容区背景，表格与表单用白色容器 |
| 强调色 Accent | `#245A7A` | 链接、信息提示、图表对比系列 |
| 成功 Success | `#1F7653` | 已完成 / 已通过 / 正常 |
| 危险 Danger | `#B22B31` | 驳回、超时、异常、删除确认（小面积） |
| 警示 Warn | `#A9711F` | 待审批、待协调、临期 |
| 正文 | `#1B2A38` | 主文字 |
| 次文 | `#5A6D7C` / `#8A9AA8` | 描述 / 辅助说明 |
| 分隔线 | `#DDE7EF` | 卡片边框、表格横线 |

图表系列色：`#0F3B5D` → `#2878B5` → `#4FA3D9` → `#1F7653` → `#A9711F`，同一含义跨页面固定。
状态永远「颜色 + 中文文字 + 圆点」三重表达，不单靠颜色。

## 2. 字体阶梯

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | 19 / 1.4 | 650 | 内容区 h1 |
| 卡片标题 | 13.5 / 1.4 | 650 | card 头部 |
| 正文 | 13 / 1.6 | 400 | 表格、表单、描述 |
| 辅助 | 12.5 / 1.5 | 400 | 筛选标签、分页 |
| 说明 | 11.5 / 1.5 | 400 | 副标题、时间、单位 |

数字列统一 `font-variant-numeric: tabular-nums`（`.num`），保证金额/容量/得分对齐。
字体族：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。

## 3. 栅格与间距

- 桌面端：左侧菜单 220px（折叠后 64px 仅留图标）、顶栏 56px、内容区自适应。
- 内容区内边距 20/24px，卡片间距 12px，卡片内边距 14px。
- 栅格：`grid2` 1:1、`grid2-1` 2:1、`grid3` 1:1:1、`kpis` 6 列等宽。
- 表单标签 100–120px，单列输入 360–520px，搜索下拉 180–240px（`.sel` 默认 196px）。
- 圆角：卡片 8px、按钮/输入 6px、标签 4px、头像 50%。

## 4. 组件清单（详见 components.md）

按钮 4 类、输入 3 类、筛选栏、快捷标签页、表格、状态标签 5 色、分页、指标卡、图表 4 类、时间轴、描述列表、进度条、甘特条、抽屉、空状态、门户卡片、登录页。

## 5. 角色与视觉区分

| 角色 | 入口 | 视觉 |
|---|---|---|
| 系统管理员 | 后台 | 深钴蓝侧边栏 + 全量菜单，主色强调 |
| 场馆工作人员 | 后台 | 同框架，菜单收敛到核销/维护/设备，顶栏显示岗位 |
| 赛事管理员 | 后台 | 同框架，赛事与排期为主菜单 |
| 团体负责人 | 门户 + 后台混合 | 门户导航（深蓝 64px 顶栏）提交申请，后台只看本人单据 |
| 普通用户 | 门户（前台风格） | 搜索条 + 场馆卡片网格 + 我的预约卡片 |

## 6. 交互约定

- 行内最多「查看 + 2 个高频操作」，其余进「更多」。
- 审批、流转、核验一律用右侧 480px 抽屉，抽屉内保留单据摘要。
- 危险操作红色描边按钮 + 二次确认；普通取消不用强提醒。
- 加载 > 300ms 显示表格骨架，禁止整页白屏。
- 空状态说明原因与下一步（如「当前筛选无记录，清空筛选或新建预约」）。
- 时间统一 `yyyy-MM-dd HH:mm:ss`，日期段用 date-range 组件，不用纯文本框。
